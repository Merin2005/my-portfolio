Technologies: HTML CSS

🔗 WorkLink

WorkLink is a full-stack web application designed to connect customers directly with skilled and semi-skilled workers. Customers can post jobs, and workers can apply for suitable opportunities. The application also includes role-based access and job management features.

Technologies: React.js Node.js Express.js PostgreSQL Sequelize ORM

🌱 Autonomous Smart Farming Robot

A software-based farming robot simulation that represents how a robot can navigate a farm grid, monitor simulated soil moisture values and make decisions based on predefined conditions. The project also explores sensor-data validation and the detection of unusual readings.

Concepts: Grid Navigation BFS / A* Sensor Validation

Focus: Autonomous decision-making and secure sensor validation.
